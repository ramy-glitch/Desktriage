# AI

I use AI to help me brainstorm ideas, reflect about the problem, search for relevant resources for my defined problem, create diagrams of the system Architecture or the data flow in order to help me think clearly and anticipate problems that i would face along the way. I also use AI to create scenarios to test my application, and in coding but i verify each line of code and make sure everything is working as it supposed to be.

## Tools I used

I use cursor for assisstance with code and project organisation.

I use other AI tools like chatgpt and Claude for research and reflection.

## A suggestion that was wrong or unhelpful

For instance, when claude suggested a system architecture it created more containers and separation, which means increasing networking load, creating more images, more testing checks, more configuration, and more to debug. The separation of concerns can exist within one image (or container), so there's no good argument for its suggestion. 

## How I checked what I kept

I always ask the AI to provide sources about what it is saying, i manually check the sources.
